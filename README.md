# 민감정보 안심마스커

한글(HWPX) 문서에서 **개인정보만 골라 가리는** 웹앱입니다.
파일은 **브라우저 메모리 안에서만** 처리되고, 어디에도 전송·저장되지 않습니다.

- 라이브: <https://hwpx-masker.vercel.app/>
- 저장소: <https://github.com/MinseoHaeseoFa/hwpx-masker>

> AI에게 문서를 넘기기 전, 또는 외부에 자료를 보내기 전에 딱 한 번 쓰는 도구입니다.
> 가린 뒤에도 표·글자 모양·병합 셀 등 **원본 서식은 그대로** 남습니다.

---

## 무엇을 하나요

| 단계 | 내용 |
| --- | --- |
| 1. 열기 | `.hwpx` 파일을 끌어다 놓거나 선택. 구형 `.hwp`는 한글에서 **다른 이름으로 저장 → HWPX 문서**로 변환 안내 |
| 2. 자동 탐지 | 주민등록번호·외국인등록번호 / 휴대·유선전화 / 이메일 / 계좌·카드번호 / 사업자·법인등록번호 / 차량번호 / 상세주소 / 생년월일 — 항목별 ON·OFF |
| 3. 맞춤 치환 | 표 라벨(`성명`·`대상자`·`피감사인`·`부서`·`소속`·`기관명`·`업체명`) 옆 값만 후보로 추천. 미리보기에서 단어를 **더블클릭·드래그**하거나 직접 입력하면 문서 전체에 일괄 적용 |
| 4. 확인 | 탐지·지정된 항목을 `원본 → 가린 결과`로 보여주고, 개별 체크로 제외. 본문에서 가려질 자리는 하이라이트 |
| 5. 내보내기 | `원본이름_masked.hwpx` 다운로드 / AI 입력용 마스킹 텍스트 복사 |

### 가리는 방식(예시)

| 종류 | 예 |
| --- | --- |
| 주민등록번호 | `700223-1234567` → `700223-1******` |
| 휴대전화 | `010-8990-0543` → `010-****-0543` |
| 유선전화 | `041-589-8000` → `041-***-8000` |
| 이메일 | `hong@kitech.re.kr` → `***@kitech.re.kr` |
| 계좌번호 | `123-456-789012` → `123-***-******` |
| 카드번호 | `1234-5678-9012-3456` → `1234-****-****-****` |
| 사업자등록번호 | `123-45-67890` → `123-**-*****` |
| 차량번호 | `12가 3456` → `12가 ****` |
| 상세주소 | `충청남도 천안시 동남구 대흥로 123, 4층 402호` → `충청남도 천안시 동남구 **** ***, *층 ***호` |
| 생년월일 | `생년월일 1970.02.23` → `생년월일 1970.**.**` |
| 성명(라벨) | `홍길동` → `홍OO` |
| 부서·소속(라벨) | `감사실` → `OO실` |

**일반 감사 기간·금액은 건드리지 않습니다.** `2026.01.01. ~ 2026.12.31.`, `12,345,000원` 같은 값은 그대로 남고,
특정 금액을 가리려면 미리보기에서 그 금액을 골라 추가하면 됩니다(`3,250,000원` → `*,***,***원`).

## 왜 서식이 깨지지 않나요

`.hwpx`는 ZIP 컨테이너입니다.

1. `Contents/section*.xml`만 파싱해 문단(`<hp:p>`) 단위로 글자를 모읍니다.
   한 단어가 여러 `<hp:t>` 조각으로 쪼개져 있어도(run split) 문단 안에서 이어 붙여 찾습니다.
2. 찾은 구간에 걸친 글자만 바꾸고, `<hp:run charPrIDRef="…">`·표(`<hp:tbl>`)·병합(`<hp:cellSpan>`)·스타일 정의는 손대지 않습니다.
3. 나머지 엔트리(`mimetype`, `META-INF/*`, `BinData/*`, `settings.xml`, `Contents/header.xml`)는 **원본 바이트 그대로** 다시 담습니다.
4. `mimetype`은 OCF 규격대로 **첫 번째 엔트리 + 무압축(STORE)** 으로 기록합니다.
5. 문서 안에 들어 있는 미리보기 흔적도 정리합니다(기본 켜짐):
   `Preview/PrvText.txt`는 가린 텍스트로 다시 쓰고, `Preview/PrvImage.png`는 빈 이미지로 바꿉니다.
   (원본 텍스트·썸네일이 그대로 남아 있으면 마스킹이 무의미해지기 때문입니다.)

## 개인정보 처리

- 파일은 `FileReader`/`ArrayBuffer`로 읽어 **브라우저 메모리에서만** 처리합니다.
- 서버·CDN·분석 도구로 보내는 요청이 **없습니다**. JSZip도 저장소에 포함된 로컬 파일을 씁니다.
- 새로고침하면 작업 내용이 사라집니다(어디에도 저장하지 않음).
- 네트워크를 끊고 열어도 동작합니다.

검증 스크립트가 실제로 **외부 네트워크 요청 0건**을 확인합니다.

## 로컬에서 열기

정적 파일만으로 동작합니다. 빌드 단계가 없습니다.

```sh
# 아무 정적 서버나 사용
python3 -m http.server 8080
# → http://localhost:8080/
```

`index.html`을 파일로 직접 열어도(`file://`) 동작합니다.

## 검증

```sh
python3 tools/make_sample.py      #「감사 처분요구서(가상)」 샘플 .hwpx 생성 (rhwp 필요)
python3 tests/verify_e2e.py       # Playwright 전수 검증 + 스크린샷
```

`tests/verify_e2e.py`가 확인하는 것:

- 샘플 열기 → 8종 자동 탐지·라벨 후보·미리보기 하이라이트
- `_masked.hwpx` 다운로드 → ZIP/XML 무결성
  - `mimetype` 첫 엔트리·무압축, 나머지 엔트리 목록 보존
  - 민감정보 **전량 치환**(원본 문자열 부재 확인) / 일반 금액·기간 **보존**
  - XML 요소 개수·`charPrIDRef` 순서·표 구조(행·열·병합)가 원본과 동일
  - `PrvText`·썸네일에 원본 개인정보 없음
  - 여러 번 내려받아도 결과가 훼손되지 않음
  - 한글 엔진(`rhwp`)이 산출물을 HWPX로 인식하고 PDF 렌더까지 성공
- 카테고리 토글, 맞춤 치환 추가, 텍스트 복사
- 날짜·일반 금액을 개인정보로 오인하지 않는지 탐지 규칙 매트릭스로 확인
- 콘솔 에러 0건 · 외부 요청 0건 · 모바일 390px 가로 스크롤 없음
- 스크린샷: `downloads/hwpx-masker-2026-11-26/`

현재 결과: **87 / 87 통과**(탐지 규칙 매트릭스 16건 포함).

## 한계

- `.hwp`(구형 바이너리)는 지원하지 않습니다. 한글에서 HWPX로 저장해야 합니다.
- 미리보기는 글자 흐름을 보여주는 **근사 화면**입니다. 각주·머리말·도형 안의 글자는 미리보기에 나오지 않아도
  실제 저장 파일에서는 함께 가려집니다(문단 단위로 처리하므로). 최종 서식은 한글에서 연 파일이 기준입니다.
- 암호가 걸린 문서, DRM 문서는 열리지 않습니다.
- 이름·부서·금액은 자동으로 추측하지 않습니다(오탐 방지). 라벨 후보 + 직접 지정만 사용합니다.
