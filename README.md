# 민감정보 안심마스커

한글(HWPX) 문서에서 **개인정보만 골라 가리는** 웹앱입니다.
파일은 **브라우저 메모리 안에서만** 처리되고, 어디에도 전송·저장되지 않습니다.

- 라이브: <https://hwpx-masker.vercel.app/>
- 저장소: <https://github.com/MinseoHaeseoFa/hwpx-masker>

> AI에게 문서를 넘기기 전, 또는 외부에 자료를 보내기 전에 딱 한 번 쓰는 도구입니다.
> 가린 뒤에도 표·글자 모양·병합 셀 등 **원본 서식은 그대로** 남습니다.

---

## 무엇을 하나요

| 단계 | 내용 |
| --- | --- |
| 1. 열기 | `.hwpx` 파일을 끌어다 놓거나 선택. 구형 `.hwp`는 한글에서 **다른 이름으로 저장 → HWPX 문서**로 변환 안내 |
| 2. 자동 탐지 | 주민등록번호·외국인등록번호 / 휴대·유선전화 / 이메일 / 계좌·카드번호 / 사업자·법인등록번호 / 차량번호 / 상세주소 / 생년월일 — 항목별 ON·OFF |
| 3. 맞춤 치환 | 표 라벨(`성명`·`대상자`·`피감사인`·`부서`·`소속`·`기관명`·`업체명`) 옆 값만 후보로 추천. 미리보기에서 단어를 **더블클릭·드래그**하거나 직접 입력 |
| 4. 영향 범위 확인 | 바꾸기 전에 **어떤 문맥이 몇 곳** 바뀌는지 보여 주고, 문맥별 체크로 **제외**할 수 있음. 기본은 **단어 일치**(`감사`가 `피감사인` 속 글자를 건드리지 않음), 필요하면 **부분 일치** |
| 5. 검수 | `마스킹 후 / 원문 / 전후 비교` 3가지 뷰. 전후 비교는 바뀌는 문단만 모아 **원문(노랑·취소선) vs 이후(초록)** 로 보여 줌. 머리말·꼬리말·각주·글상자도 함께 점검 |
| 6. 내보내기 | `원본이름_masked.hwpx` 다운로드 / AI 입력용 마스킹 텍스트 복사. 문서 메타데이터 초기화·미리보기 흔적 정리 옵션 |

### 가리는 방식(예시)

| 종류 | 예 |
| --- | --- |
| 주민등록번호 | `700223-1234567` → `700223-1******` |
| 휴대전화 | `010-8990-0543` → `010-****-0543` |
| 유선전화 | `041-589-8000` → `041-***-8000` |
| 이메일 | `hong@kitech.re.kr` → `***@kitech.re.kr` |
| 계좌번호 | `123-456-789012` → `123-***-******` |
| 카드번호 | `1234-5678-9012-3456` → `1234-****-****-****` |
| 사업자등록번호 | `123-45-67890` → `123-**-*****` |
| 법인등록번호 | `110111-1234567` → `110111-*******` (라벨이 `법인등록번호`일 때) |
| 차량번호 | `12가 3456` → `12가 ****` |
| 상세주소 | `충청남도 천안시 동남구 대흥로 123, 4층 402호` → `충청남도 천안시 동남구 *** **** ** ****` |
| 생년월일 | `생년월일 1970.02.23` → `생년월일 1970.**.**` |
| 성명(라벨) | `홍길동` → `홍OO` |
| 부서·소속(라벨) | `감사실` → `OO실` |

**일반 감사 기간·금액은 건드리지 않습니다.** `2026.01.01. ~ 2026.12.31.`, `12,345,000원` 같은 값은 그대로 남고,
특정 금액을 가리려면 그 금액을 골라 추가하면 됩니다(`3,250,000원` → `*,***,***원`).

### v2에서 달라진 점

1. **카테고리 토글 완전 동기화** — 토글을 끄면 탐지 항목·건수·미리보기 하이라이트·실제 치환 대상이 그 자리에서 함께 바뀝니다.
   자동 탐지 항목은 "어디서 찾았는지"를 기억하므로, 전화번호가 계좌번호로 재분류되어 남는 일이 없습니다.
   `주민등록번호`와 `법인등록번호`처럼 모양이 같은 6-7 숫자는 표 라벨·앞 단어(법인) 문맥으로 갈라냅니다.
2. **맞춤 치환 과잉 방지** — 단어 일치(기본)로 `감사`가 `피감사인`·`감사기간` 속 글자를 바꾸지 않습니다.
   바꾸기 전 문맥·건수를 보여 주고, 문맥별로 뺄 수 있습니다. 부분 일치도 선택 가능.
3. **본문 외 영역 점검 + 전후 비교** — 머리말·꼬리말·각주·글상자도 미리보기와 복사 텍스트에 포함하고,
   바뀌는 문단만 모은 비교 뷰로 다운로드 전에 검수합니다.
4. **메타데이터 초기화** — `Contents/content.hpf`(작성자·최종수정자·제목·요약·날짜)와 `settings.xml`(최근 경로·사용자 이름),
   `Contents/header.xml`의 작성자 계열 값을 한 번에 비웁니다(체크박스, 기본 켜짐).
5. **마스킹 세트 프리셋** — 지금 설정(탐지 항목 + 맞춤 치환 규칙)을 이름 붙여 `localStorage`에만 저장/불러오기/삭제.
   공용 PC를 위해 **저장된 프리셋 모두 지우기**(2단계 확인) 포함.
6. **Web Worker + 진행률** — 압축 해제·XML 파싱·치환·재압축을 워커에서 처리하고 `%` 진행률을 표시합니다.
   약 10MB XML(2만 3천 문단) 문서도 화면이 멈추지 않고 처리됩니다.

## 왜 서식이 깨지지 않나요

`.hwpx`는 ZIP 컨테이너입니다.

1. `Contents/section*.xml`을 **문자열 단위**로 읽어 문단(`<hp:p>`)과 글자 조각(`<hp:t>`)의 위치를 기록합니다.
   한 단어가 여러 `<hp:t>` 조각으로 쪼개져 있어도(run split) 문단 안에서 이어 붙여 찾습니다.
2. 바뀌는 곳은 `<hp:t>` 안의 글자뿐입니다. 나머지 바이트(태그·속성·공백·XML 선언)는 **원본 그대로** 남깁니다.
   DOM 재직렬화를 하지 않으므로 표(`<hp:tbl>`)·병합(`<hp:cellSpan>`)·스타일 정의가 흔들리지 않습니다.
3. 나머지 엔트리(`mimetype`, `META-INF/*`, `BinData/*`, `Contents/header.xml`)는 원본 바이트로 다시 담습니다.
4. `mimetype`은 OCF 규격대로 **첫 번째 엔트리 + 무압축(STORE)** 으로 기록합니다.
5. 문서 안의 미리보기 흔적도 정리합니다(기본 켜짐):
   `Preview/PrvText.txt`는 가린 텍스트로 다시 쓰고, `Preview/PrvImage.png`는 빈 이미지로 바꿉니다.

## 개인정보 처리

- 파일은 `ArrayBuffer`로 읽어 **브라우저 메모리에서만** 처리합니다. Worker는 같은 페이지의 로컬 스크립트입니다.
- 서버·CDN·분석 도구로 보내는 요청이 **없습니다**. JSZip도 저장소에 포함된 로컬 파일을 씁니다.
- 프리셋만 `localStorage`에 저장되며, 그마저도 '모두 지우기'로 즉시 삭제할 수 있습니다.
- 새로고침하면 문서 작업 내용은 사라집니다(어디에도 저장하지 않음).
- 네트워크를 끊고 열어도 동작합니다(Worker를 못 쓰는 환경은 메인 스레드로 자동 전환).

검증 스크립트가 실제로 **외부 네트워크 요청 0건**을 확인합니다.

## 로컬에서 열기

정적 파일만으로 동작합니다. 빌드 단계가 없습니다.

```sh
python3 -m http.server 8080
# → http://localhost:8080/
```

`index.html`을 파일로 직접 열어도(`file://`) 동작합니다(이때는 Worker 대신 메인 스레드로 처리).

## 검증

```sh
python3 tools/make_sample.py      # 샘플 .hwpx + sample-data.js + build/stress.hwpx 생성 (rhwp 필요)
python3 tests/verify_e2e.py       # Playwright 전수 검증 + 스크린샷
python3 tests/verify_live.py      # 배포본 라이브 검증
```

`tests/verify_e2e.py`가 확인하는 것:

- 샘플 열기 → 8종 자동 탐지·라벨 후보·머리말/꼬리말/각주 점검·Worker 표시
- 카테고리 토글: 배지·목록·하이라이트·치환 건수가 즉시 동기화, 전화→계좌 재분류 없음
- 맞춤 치환: 단어 일치(기본)·부분 일치 전환, 문맥별 제외, `피감사인` 과잉 치환 방지
- 원문/마스킹 후/전후 비교 3개 뷰
- 프리셋 저장·불러오기·삭제·모두 지우기(localStorage)
- `.hwpx` 다운로드 → ZIP/XML 무결성
  - `mimetype` 첫 엔트리·무압축, 나머지 엔트리 목록 보존
  - 민감정보 **전량 치환**(원본 문자열 부재) / 일반 금액·기간 **보존**
  - XML 요소 개수·`charPrIDRef` 순서·표 구조(행·열·병합)·문단 수가 원본과 동일
  - 메타데이터 초기화 ON/OFF 각각 확인, 본문 결과는 동일
  - `PrvText`·썸네일 정리, 한글 엔진(`rhwp`) 인식 및 PDF 렌더
- Worker 없이(`?noworker=1`)도 동작
- 약 10MB XML 대용량 문서: 문단 2만 3천 개 처리, 처리 중 UI 프레임 유지, 진행률 표시, 산출물 무결성
- 콘솔 에러 0건 · 외부 요청 0건 · 모바일 390px 가로 스크롤 없음
- 스크린샷·산출물: `downloads/hwpx-masker-v2-2026-11-27/`

현재 결과: **161 / 161 통과**.

## 한계

- `.hwp`(구형 바이너리)는 지원하지 않습니다. 한글에서 HWPX로 저장해야 합니다.
- 미리보기는 글자 흐름을 보여주는 **근사 화면**입니다. 아주 큰 문서는 미리보기 앞부분만 그립니다(치환은 전체 적용).
- 암호가 걸린 문서, DRM 문서는 열리지 않습니다.
- 이름·부서·금액은 자동으로 추측하지 않습니다(오탐 방지). 라벨 후보 + 직접 지정만 사용합니다.
- 메타데이터 초기화는 `content.hpf`·`settings.xml`·`header.xml`의 작성자 계열 값만 비웁니다(문서 서식 정의는 유지).
